# Wanderlux

Wanderlux is a responsive travel discovery experience built with React, TypeScript, Vite, Three.js, and Motion.

## Local development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

The `dist` directory is ready to deploy to Vercel or any static hosting provider. No environment variables are required. Weather and currency information are explicitly presented as sample data; the enquiry form validates locally and does not send messages to a server.
